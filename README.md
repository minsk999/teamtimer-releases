# ADEF 영상팀 작업 타이머

팀 내부용 데스크탑 앱 — Google Sheets 업무현황 동기화 + 인트라넷 메일 알림.

## 다운로드
👉 **[최신 버전 받기 (Releases)](https://github.com/minsk999/teamtimer-releases/releases/latest)**
- Windows: `TeamTimer-Setup-x.x.x.exe`
- macOS: `TeamTimer-x.x.x-universal.dmg` — 설치 후 터미널에서 `xattr -cr "/Applications/작업 타이머.app"` 한 번 실행
