광고창 차단 (AdPopupBlock) — Windows

윈도우를 켤 때 광고 팝업을 띄우는 프로그램의 광고창과 카카오톡 광고를 막아요.
  - 디자인210 FontManager : 시작할 때 뜨는 광고 팝업
  - 산돌구름              : 광고·공지 팝업창
  - 네이트온              : 로그인 광고 팝업, 광고 알림창, 정각 광고
  - 카카오톡              : 친구·채팅 목록 아래 광고 (그 자리만큼 목록이 늘어나요)

설치
  1. 이 폴더(AdPopupBlock)를 계속 둘 곳으로 옮겨요. (예: C:\Users\내이름\Tools)
     자동 실행이 이 위치를 기억하니, 나중에 옮기면 4번을 다시 해 주세요.
  2. AdPopupBlock.exe 를 더블클릭해요.
     - 파란 "Windows의 PC 보호" 창이 뜨면 → 추가 정보 → 실행
     - "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 창이 뜨면 → 예
       (디자인210 이 관리자 권한으로 돌아서, 그 설정을 고치려면 관리자 권한이 필요해요)
  3. 작업 표시줄 오른쪽 트레이에 파란 방패 아이콘이 생기면 실행된 거예요.
  4. 트레이 아이콘 우클릭 → "윈도우 시작 시 자동 실행" 을 체크해요.
     (다음부터는 부팅할 때 묻지 않고 바로 켜져요)

끄고 켜기
  - 트레이 아이콘 우클릭 → 프로그램 이름의 체크를 풀면 그 프로그램만 차단을 멈춰요.
  - 완전히 끄려면 "종료". 자동 실행도 그만두려면 "윈도우 시작 시 자동 실행" 체크 해제 후 종료.
  - 무엇을 막았는지는 "기록 보기" 에서 볼 수 있어요.

참고
  - 디자인210 은 "하루 동안 보지 않기" 를 매일 대신 눌러 두는 방식이에요.
  - 네이트온 체크를 풀면 막아 둔 광고 설정 파일을 풀어 줘요(다음 로그인부터 원래대로).
  - 카카오톡 체크를 풀면 카카오톡을 다시 켤 때부터 광고가 보여요.
  - 다른 카카오톡 광고 차단 프로그램(KakaoTalkAdBlock 등)과 같이 켜 두지 마세요. 둘이 창 크기를 두고 다퉈 깜빡일 수 있어요.
