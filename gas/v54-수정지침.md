## 1) 【버그】 READ_ROWS 미설정으로 150행 아래가 사라진다

`ensureMembers()`는 팀원 캐시(60초)에 적중하면 **READ_ROWS 를 정하지 않고 조기 반환**한다.
그러면 `doRead()`가 기본값 150행으로 시트를 읽어, 시트가 150행을 넘는 순간
그 아래 작업이 **조용히 사라진다**. 캐시가 살아있는 60초 동안만 간헐적으로 나타나 잡기 어렵다.
(2026-08-27 실측: 현재 시트 마지막 항목이 93행 — 아직 안전하지만 여유가 얼마 없다)

### 추가 — `var READ_COLS = 15;` 바로 아래에 넣는다

```js
// ── 그리드 1회 읽기 (v54) ────────────────────────────────────
// 요청 1건에서 A~O 전체를 딱 한 번만 읽는다.
// 예전엔 ensureMembers 와 doRead 가 같은 범위를 각각 읽어 2배로 들었다.
var _grid = null;
function readGrid(sheet) {
  if (_grid) return _grid;
  sheet = sheet || getSheet();
  // ★READ_ROWS 는 반드시 여기서 정한다. 예전엔 ensureMembers 안에서만 정해서,
  //   팀원 캐시가 살아 있으면 READ_ROWS 가 150 인 채로 doRead 가 읽었다.
  READ_ROWS = Math.max(150, sheet.getLastRow() + 20);
  var rng = sheet.getRange(1, 1, READ_ROWS, READ_COLS);
  _grid = { data: rng.getValues(), forms: rng.getFormulas() };
  return _grid;
}

// ── 읽기 응답 캐시 (v54) ─────────────────────────────────────
// ★쓰기가 일어나면 반드시 버려야 한다. 안 버리면 "완료 체크했는데 되돌아옴"이 생긴다.
var READ_CACHE_KEY = "teamtimer_read_v1";
var READ_CACHE_SEC = 20;
function bustReadCache() {
  try { CacheService.getScriptCache().remove(READ_CACHE_KEY); } catch (e) {}
}
```

## 2) 【중복 제거】 ensureMembers 가 그리드를 직접 읽지 않게

`ensureMembers()` 안, `try {` 다음의 네 줄을 바꾼다.

**찾기**
```js
    sheet = sheet || getSheet();
    // 소재가 쌓여 시트가 길어져도 잘리지 않도록 실제 크기 기준으로 확장
    READ_ROWS = Math.max(150, sheet.getLastRow() + 20);
    var rng  = sheet.getRange(1, 1, READ_ROWS, READ_COLS);
    var data = rng.getValues();
    var forms = rng.getFormulas();
```

**바꾸기**
```js
    var g = readGrid(sheet);          // v54: 요청당 1회만 읽는다
    var data = g.data, forms = g.forms;
```

## 3) 【중복 제거 + 캐시】 doRead

**찾기**
```js
function doRead(e) {
  var sheet    = getSheet();
  ensureMembers(sheet); // v51: 팀원 목록/읽기범위 확정
  var rng      = sheet.getRange(1, 1, READ_ROWS, READ_COLS);
  var allData  = rng.getValues();
  var formulas = rng.getFormulas();
```

**바꾸기**
```js
function doRead(e) {
  var only0 = (e && e.parameter && e.parameter.member) ? e.parameter.member : "";
  // v54: 전체 읽기만 캐시한다(앱이 쓰는 경로). member 지정은 진단용이라 통과.
  if (!only0) {
    try {
      var hit = CacheService.getScriptCache().get(READ_CACHE_KEY);
      if (hit) return ContentService.createTextOutput(hit).setMimeType(ContentService.MimeType.JSON);
    } catch (e0) {}
  }
  var sheet    = getSheet();
  ensureMembers(sheet); // v51: 팀원 목록/읽기범위 확정
  var g        = readGrid(sheet);   // v54: ensureMembers 가 이미 읽었으면 그걸 재사용
  var allData  = g.data;
  var formulas = g.forms;
```

그리고 같은 함수의 **마지막 return** 을 바꾼다.

**찾기**
```js
  return respond({ ok: true, members: members, memberNames: ALL_MEMBERS, warn: MEMBER_WARN });
}
```

**바꾸기**
```js
  var payload = JSON.stringify({ ok: true, members: members, memberNames: ALL_MEMBERS, warn: MEMBER_WARN });
  if (!only0) {
    // CacheService 는 키당 100KB 한도 — 넘으면 조용히 실패하므로 미리 거른다.
    try { if (payload.length < 90000) CacheService.getScriptCache().put(READ_CACHE_KEY, payload, READ_CACHE_SEC); } catch (e4) {}
  }
  return ContentService.createTextOutput(payload).setMimeType(ContentService.MimeType.JSON);
}
```

## 4) 【필수】 쓰기가 일어나면 캐시를 버린다

이걸 빠뜨리면 **"완료 체크했는데 되돌아옴"** 이 생긴다. 3번 캐시를 넣었다면 반드시 같이 넣을 것.

`doPost` 안에서 **찾기**
```js
    if (action === "read")       return doRead(e);
    if (action === "updateMemo") return updateMemo(p);
    if (action === "addMemo")    return addMemo(p);
    if (action === "toggleDone") return toggleDone(p);
    if (action === "deleteTask") return deleteTask(p);
    if (action === "updateDue")  return updateDue(p);
    if (action === "updateTask") return updateTask(p);
```

**바꾸기**
```js
    if (action === "read")       return doRead(e);

    // v54 ★쓰기 경로: 읽기 캐시를 버리고 실행한 뒤 **한 번 더** 버린다.
    //   실행 중에 다른 사람의 읽기가 옛 데이터를 다시 캐싱해 버리면
    //   내가 방금 체크한 완료가 20초 동안 되돌아온 것처럼 보인다.
    bustReadCache();
    var out = null;
    if (action === "updateMemo")      out = updateMemo(p);
    else if (action === "addMemo")    out = addMemo(p);
    else if (action === "toggleDone") out = toggleDone(p);
    else if (action === "deleteTask") out = deleteTask(p);
    else if (action === "updateDue")  out = updateDue(p);
    else if (action === "updateTask") out = updateTask(p);
    if (out) { bustReadCache(); return out; }
```

그리고 **insert(기본 경로)의 마지막 return 앞**에도 한 줄 넣는다.

**찾기**
```js
    return respond({ ok: true, message: target + " " + insertRow + "행 추가됨 (섹션끝:" + scanEnd + ", needBlank:" + needBlank + ")" });
```

**바꾸기**
```js
    bustReadCache();   // v54
    return respond({ ok: true, message: target + " " + insertRow + "행 추가됨 (섹션끝:" + scanEnd + ", needBlank:" + needBlank + ")" });
```

## 적용 후 확인

1. 편집기에서 `testRead()` 실행 → 팀원 7명, 작업 수가 지금과 같은지
2. `testMemberList()` 실행 → 경고 없음
3. **배포 → 배포 관리 → 편집(연필) → 버전 "새 버전" → 배포**
   ⚠️ 새 배포를 만들면 URL 이 바뀐다. 반드시 **기존 배포를 편집**할 것.
4. 앱에서 동기화 두세 번 — 콘솔에 `[sync] ...ms` 가 찍힌다. 두 번째부터 빨라져야 한다.
5. **완료 체크 → 바로 동기화** 해서 체크가 유지되는지 확인 (4번 무효화 검증)

## 되돌리기
캐시만 끄고 싶으면 `READ_CACHE_SEC` 를 `0` 으로. 1·2번(중복 읽기 제거)은 그대로 둬도 안전하다.
