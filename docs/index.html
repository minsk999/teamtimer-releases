작업 타이머는 구글 시트의 업무 현황과 연동되는 데스크톱 앱이에요. 마감 카운트다운, 알람, 메일 알림을 한 곳에서 관리해요. Windows와 macOS 모두에서 동작합니다.

Windows macOS 구글 시트 연동 메일 알림
01

시작하기 - 설치

아래에서 OS에 맞는 설치 파일을 받아 실행하면 돼요. 접속하신 기기에 맞춰 탭이 자동으로 선택됩니다.

접속 기기: Windows · 설치 탭이 자동 선택돼요
Windows · 작업 타이머 v1.0.13
Windows 데스크톱 앱 설치 파일
다운로드 EXE
  1. 위에서 다운로드(EXE)를 눌러 받은 설치 파일을 더블클릭해요.
  2. 파란 “Windows의 PC 보호” 창이 뜨면 → 추가 정보 → 실행을 눌러요. (사내용 앱이라 정상이에요.)
  3. 설치 위치와 바탕화면 바로가기를 선택하고 설치를 마쳐요.
  4. 바탕화면 또는 시작 메뉴의 작업 타이머 아이콘으로 실행해요.
macOS · 작업 타이머 v1.0.13
본인 Mac 칩에 맞는 버전을 받으세요. (사과 메뉴 → 이 Mac에 관하여에서 확인)
Apple Silicon DMG Intel DMG
!어떤 버전을 받아야 하나요? 화면 왼쪽 위 사과 메뉴 → 이 Mac에 관하여에서 칩을 확인하세요. Apple M1/M2/M3/M4면 Apple Silicon, Intel이면 Intel 버전을 받으면 돼요.
  1. 받은 .dmg를 더블클릭해서 열어요.
  2. 앱 아이콘을 응용 프로그램(Applications) 폴더로 드래그해요.
  3. 앱은 Apple 서명이 없어 처음엔 차단돼요. 터미널(Terminal)을 열고 아래 한 줄을 실행해 “격리” 표시를 제거하세요.
    xattr -cr "/Applications/작업 타이머.app"
  4. 이제 앱을 더블클릭하면 정상 실행돼요. (한 번만 하면 이후엔 그냥 열려요)
i이 한 줄은 인터넷에서 받은 파일에 붙는 “격리” 표시만 떼어내요 — 인텔·애플실리콘 모두 이 방법으로 열려요. (예전의 “시스템 설정 → 확인 없이 열기”는 애플실리콘에선 옵션이 안 나와서, 이 방법이 가장 확실해요.)

인트라넷 딸깍 (크롬 확장)

인트라넷 영상 요청글을 클릭 한 번으로 구글 시트에 등록하는 크롬 확장프로그램이에요. 크롬·엣지 등 크로미움 브라우저에서 써요.

인트라넷 딸깍 확장 v1.4
크롬 확장프로그램 (압축 파일)
다운로드 ZIP
  1. 위에서 다운로드(ZIP)를 눌러 받은 파일의 압축을 풀어요. (폴더 위치는 지우지 않을 곳에 두세요. 이 폴더를 지우면 확장도 사라져요.)
  2. 크롬 주소창에 chrome://extensions 를 입력해 확장 프로그램 페이지를 열어요.
  3. 오른쪽 위 개발자 모드를 켜요.
  4. 압축해제된 확장 프로그램을 로드를 눌러, 1번에서 압축 푼 폴더를 선택해요.
  5. 툴바에 딸깍 아이콘이 생겨요. (안 보이면 퍼즐 🧩 아이콘 → 딸깍 고정 📌)
  6. 처음 한 번 ⚙️ 설정 탭에서 본인 이름과 구글 시트 웹앱 URL을 입력하고 저장해요.
i인트라넷 영상 요청글 페이지를 연 상태에서 딸깍 아이콘을 누르고 현재 페이지 불러오기 → 구글 시트로 전송하면 끝이에요.
!업데이트할 때는 새 ZIP을 받아 같은 폴더에 덮어쓴 뒤, chrome://extensions에서 딸깍의 새로고침 ⟳ 버튼을 눌러요. (제거 후 재설치하면 저장한 설정이 초기화돼요.)
02

처음 설정

앱을 처음 켜면 두 가지만 해두면 바로 쓸 수 있어요.

① 내 이름 선택

우측 상단 설정(톱니)을 열고 “내 이름”에서 본인을 선택해요. 시트에서 내 작업만 불러오기 위해 필요해요.

② 메일 연동

설정의 메일 연동에서 구글 계정으로 로그인하면, 인트라넷 업무요청 메일 알림을 받을 수 있어요.

i이름·메일 로그인·단축키는 앱을 업데이트(재설치)해도 그대로 유지돼요.
03

작업 보드 보기

각 작업이 카드로 표시되고, 마감까지 남은 시간이 실시간으로 줄어들어요.

[클리오] 6월 올영캠 영상 3건 편집
오늘 18:00
2:14
i왼쪽 체크로 완료 처리, 마감칩 옆 요청글·기획안 링크(아이콘)를 누르면 브라우저로 열려요. 우측의 편집(연필)·삭제(휴지통)로 작업을 수정하거나 지울 수 있어요. 가운데 숫자는 마감까지 남은 시간이에요.
i버튼이 아닌 카드의 빈 영역을 클릭하면 그 작업의 요청글이 바로 열려요.

상단 통계 색의 의미

마감 임박 - 마감이 코앞이거나 이미 지난 작업
오늘 마감 - 오늘 안에 끝내야 하는 작업
여유 있음 - 아직 시간이 넉넉한 작업
i이 통계 영역을 클릭하면 구글 시트(업무 현황)가 열려요. 색은 설정에서 바꿀 수 있어요(아래 “맞춤 설정”).
04

마감 편집

카드의 마감칩(또는 연필)에서 날짜와 시간을 바꿀 수 있어요.

  • 프리셋으로 빠르게 - 오전 / 오후 / EOD 등 자주 쓰는 시간을 한 번에 선택해요. (프리셋은 설정에서 바꿀 수 있어요.)
  • 직접 입력 - 날짜를 고르고 시간을 입력해요. 숫자만 쳐도 자동 인식돼요: 1111 → 11:11
  • 시간 입력 후 Enter 를 치거나 다른 곳을 클릭하면 바로 반영돼요.
05

알람

마감 전에 미리 알림을 받을 수 있어요. 메일 탭에 있거나 창을 닫아 트레이에 있어도 알림이 와요.

작업별 알람

작업을 추가·편집할 때 “N분 전”(10분·30분·1시간·3시간 전)을 선택하면, 그 시점에 알림과 소리가 울려요.

알람 방식 · 소리

설정에서 알림/소리를 켜고 끌 수 있고, 알림음(딩·벨·차임)이나 직접 업로드한 음원을 쓸 수 있어요. 음량은 0~200%까지 조절돼요.

i커스텀 음원은 이름을 클릭하면 교체, 옆 ×로 삭제할 수 있어요. (mp3·wav·ogg / 5MB·10초 이하)
06

메일

인트라넷 업무요청 메일을 앱 안에서 확인해요.

  • 상단의 메일 ↔ 타이머 전환으로 메일 목록을 볼 수 있어요.
  • 새 메일이 오면 알림(메일 제목 포함)이 뜨고, 안 읽은 메일 수만큼 표시돼요.
  • 메일을 누르면 설정한 방식대로 열리고(아래 참고), 자동으로 읽음 처리돼요.
  • 메일 위에 마우스를 올리면 우측에 휴지통이 나타나요. 누르면 목록에서 사라지고 Gmail에서도 휴지통으로 이동해요.
  • 최신순 토글로 정렬을 바꿀 수 있어요.
  • 안 읽은 메일이 있으면 작업표시줄(Windows) 또는 Dock(macOS) 아이콘에 빨간 표시가 떠요.

메일을 누르면 무엇을 열지 (설정)

설정 → 메일 연동 → “메일을 누르면”에서 고를 수 있어요.

  • Gmail — Gmail 웹에서 메일을 열어요. (기본값)
  • 요청글 — 메일 본문에 담긴 인트라넷 요청글을 바로 열어요.
  • 둘 다 — Gmail과 인트라넷 요청글을 함께 열어요.
i요청글 링크를 메일에서 못 찾으면 자동으로 Gmail을 대신 열어요. 어떤 방식이든 누른 메일은 읽음 처리돼요.

알림창 클릭

  • 새 메일 알림창을 클릭하면, 위에서 고른 방식(Gmail / 요청글 / 둘 다)대로 그 메일이 열려요.
  • 알림을 클릭하면 앱 창이 다시 떠요.
!macOS 사용자 — 알림이 뜨려면 시스템 설정 → 알림에서 ‘작업 타이머’ 알림이 켜져 있어야 해요. (서명되지 않은 앱이라 드물게 알림이 안 뜰 수 있어요. 메일 목록에서 직접 누르는 건 항상 정상 동작해요.)
07

동기화

앱과 구글 시트(업무 현황)는 양방향으로 연결돼 있어요.

  • 앱에서 완료 체크 / 마감 변경 / 작업 추가·삭제를 하면 시트에 반영돼요.
  • 시트가 바뀌면 앱도 약 10분 간격으로 자동 동기화돼요. 또한 앱 창에 다시 돌아오면(클릭해서 포커스) 마지막 동기화가 3분 넘게 지났을 때 자동으로 한 번 더 동기화해요 — 그래서 돌아온 직후엔 대부분 이미 최신 상태예요.
  • 지금 바로 동기화하려면 동기화 버튼을 누르거나 Space 를 눌러요. (메일 탭에서는 메일 새로고침)
08

맞춤 설정

설정에서 색과 링크 열기 방식을 취향에 맞게 바꿀 수 있어요.

상태 색상

마감 임박 · 오늘 마감 · 여유 있음의 색을 바꿀 수 있어요. 팔레트에서 고르거나, 색 동그라미를 눌러 직접 선택(색상환·채도·HEX)할 수 있어요. 카드의 좌측 바·통계·카운트다운에 바로 반영돼요.

링크 열기 (Chrome 프로필)

링크를 열 Chrome 프로필(계정)을 고르면, 메일·요청글·기획안·시트 등 모든 링크가 그 프로필로 열려요. 회사 계정으로 지정해두면 편해요. 다른 프로필 로그인은 건드리지 않아요.

i“링크 열기”는 Chrome 전용이에요. 기본값은 “기본 브라우저”이고, Chrome이 없으면 자동으로 기본 브라우저로 열려요.

10

트레이 상주 & 종료

알람 앱이라, 창을 닫아도 백그라운드에 남아 알림을 보내요.

창 닫기 (X)

앱이 종료되지 않고 트레이(Windows) / 메뉴바(macOS)에 남아요. 아이콘을 클릭하면 창이 다시 떠요. (macOS는 Dock 아이콘 클릭으로도 복귀)

완전 종료

트레이/메뉴바 아이콘을 우클릭 → 종료를 누르면 앱이 완전히 꺼져요.

시작 시 자동 실행

자동 실행

설정에서 “시작 시 자동 실행”을 켜면, 컴퓨터를 켤 때 작업 타이머가 자동으로 실행돼요.

트레이로 시작

“자동 실행 시 트레이로 시작”을 켜면, 부팅 자동 실행 때 창을 띄우지 않고 트레이(메뉴바)에만 떠 있어요. 직접 아이콘을 눌러 켤 땐 항상 창이 보여요.

i“트레이로 시작”은 부팅 자동 실행으로 켜졌을 때만 적용돼요. 처음 적용하려면 옵션을 켠 상태로 한 번 재부팅이 필요해요. (트레이에 있어도 알람·메일 알림은 정상 동작)
11

팀원 보드 보기

  • Q E 또는 좌우 화살표로 다른 팀원의 보드를 넘겨볼 수 있어요.
  • 다른 팀원 보드는 읽기 전용이라, 편집·완료 처리는 내 보드에서만 돼요.
  • Esc 또는 Home 으로 내 보드로 돌아와요.
12

패키징 (빌드)

설치 파일(.exe / .dmg)을 직접 만드는 방법이에요. 보통은 팀장이 빌드해 배포하니, 일반 사용자는 이 부분을 건너뛰어도 돼요. 맥용 설치 파일은 반드시 맥에서 빌드해야 해요 — 윈도우에서는 맥용 dmg를 만들 수 없어요. 맥이 없으면 GitHub Actions로 클라우드 빌드하거나, 맥 쓰는 동료에게 빌드를 부탁하세요.

준비 · Node 22 LTS 설치(nodejs.org → LTS, 최신 “Current”는 충돌) → 새 v1.0.6 zip 압축 풀기.

  1. 압축 푼 timer-app 폴더를 파일 탐색기로 열어요.
  2. 폴더 안 빈 공간을 우클릭 → “터미널에서 열기”를 눌러요. (Windows 11)
    그 폴더 위치에서 터미널이 열려요.
  3. 관리자 권한으로 다시 열어요. 방금 열린 터미널에 아래를 붙여넣고 Enter → 뜨는 창에서 “예”. (관리자 터미널이 같은 폴더에서 새로 열려요.)
Start-Process wt -Verb RunAs -ArgumentList "-d `"$PWD`""

위가 안 되면 — 시작메뉴에서 “터미널” 우클릭 → 관리자 권한으로 실행 → 아래로 폴더 이동(경로는 본인 위치에 맞게).

cd "$env:USERPROFILE\Downloads\작업타이머-electron-v1.0.6\timer-app"

관리자 터미널이 timer-app 폴더에 있으면, 아래를 순서대로 붙여넣어요.

자주 묻는 질문

알림이 안 와요

설정에서 알림이 켜져 있는지, 그리고 OS 알림 권한(집중 모드/방해 금지)이 꺼져 있는지 확인해요. 메일 알림은 메일 연동(로그인)이 돼 있어야 해요.

macOS — 시스템 설정 → 알림에서 ‘작업 타이머’ 알림이 켜져 있어야 해요. 서명되지 않은 앱이라 드물게 알림이 안 뜰 수 있는데, 그럴 땐 메일 목록에서 직접 눌러 열면 돼요. (설정한 방식대로 — Gmail / 요청글 / 둘 다 — 열립니다.)

작업이 안 보이거나 옛날 거예요

Space(또는 동기화 버튼)로 새로고침해요. 그래도 안 맞으면 설정의 내 이름이 올바른지 확인해요.

설치할 때 경고가 떠요

사내 배포용이라 코드 서명을 하지 않았어요. Windows는 SmartScreen에서 추가 정보 → 실행. macOS는 응용 프로그램으로 옮긴 뒤 터미널에서 xattr -cr "/Applications/작업 타이머.app"를 한 번 실행하면 돼요. 안전합니다.

업데이트는 어떻게 하나요

새 설치 파일을 받아 다시 설치하면 돼요. 기존 설정(이름·로그인·단축키 등)은 그대로 유지돼요.

!문제가 계속되면 팀장(구민석)에게 화면과 증상을 알려주세요.
